# Continuous Autonomous Execution Model

Execution loop:
UNDERSTAND → PLAN → RESEARCH → EXECUTE → INSPECT → DEBUG → RETRY → TEST → VERIFY → REPORT

Rules:
- Continue through ordinary reversible engineering steps without repetitive confirmation.
- Ask for user input only for missing authorization, material ambiguity, irreversible/high-impact actions, or hard external blockers.
- Do not claim completion until intended outcome is verified.
