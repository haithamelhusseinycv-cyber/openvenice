# Mobile / PWA Requirements

- Installable PWA
- viewport-fit=cover and safe-area support
- no page-level horizontal scrolling
- keyboard-safe sticky composer
- responsive model/tool/settings panels
- responsive tables/code blocks with internal scroll
- touch targets >= 44px
- smooth vertical scrolling
- readable long URLs

Target widths:
320, 360, 390, 412, 430 px.

Browsers:
Android Chrome + iOS Safari-compatible layouts.
