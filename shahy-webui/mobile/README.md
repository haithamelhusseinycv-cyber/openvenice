# Shahy Mobile PWA

This directory contains the external Progressive Web App manifest and mask-safe application icon for the Shahy Open WebUI deployment.

Configure the Open WebUI container with:

```text
EXTERNAL_PWA_MANIFEST_URL=https://raw.githubusercontent.com/haithamelhusseinycv-cyber/openvenice/master/shahy-webui/mobile/manifest.json
```

The manifest intentionally contains no credentials. Android users can install Shahy from Chrome using **Install app** or **Add to Home screen**.
